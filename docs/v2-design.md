# 第二版：分领域关键词

沿用用户确认的浅底松绿、双列分组布局。领域标题和组内高频词采用稳定的领域色，普通词保持深灰，新闻下方的2—3个标签沿用同一分类颜色。保持现有搜索、来源、阶段、日期、收藏、CSV和来源状态功能。投资研究是用户自行执行的使用场景，不加入企业或投资推荐功能。

关键词来自真实政策标题。基础词表用于识别专业词和明确的同义词，并用中文分词和连续词组统计发现词表之外的新词。新词需至少3份去重文件且涉及至少2个发布来源，过滤套话、机构名及截断词；未能可靠归类的词显示在“其他新词”。不能保证发现每个新术语。首页默认近30天，可切7/90天，每组默认8个词并可展开。无数据不补演示词。

统计以发布日期和北京时间为准，排除缺失、无效和未来日期；同标题转载合并统计，一份文件同一词仅计一次。“新出现”是本站新识别并达到展示门槛，不等于政策新创概念；首次初始化不标新。浏览器显示分析口径、缺失日期数量和实际数据更新时间。

GitHub Actions每小时采集后生成并保存关键词索引，构建时再次校验。索引绑定原始快照；文件缺失或不匹配时由当前快照即时重建，不混用旧分析。保留GitHub仓库子路径兼容，不引入密钥、数据库、付费服务或新运行依赖。

本次更新本地News仓库并交付第二版部署包；不更改既有Sites站点。
