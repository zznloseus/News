Homepage six thematic groups plus unclassified access, OR domain multiselect, timeline default; optional independent 2-column view. Search/selected keyword must not silently distort overview.
- Central/local relation is evidence-based: full title or unambiguous document-number citation within eligible policy BODY, not title keyword/date sequence. Store excerpt + source version. If no linked root, show unmatched policies/related results honestly. Unknown issuer/region cannot be inferred merely from republishing website.
- Archive is plain text extracted from main content, with version hash and fetched time, status (text/partial/unavailable), policy source URL. Never mark summary, CAPTCHA, navigation or truncated body as complete. Preserve original versions; failed refresh retains prior text and records error. UI calls it "正文文字留存" and excludes images/attachments explicitly.
- Private storage migration, corruption recovery, capacity/write errors, sanitized import/export; individual notes have stable article/version IDs and quoted paragraph text. Multiple notes with edit/delete/undo. No uncaught rendering of imported HTML or arbitrary script/link URLs.

## Review focus

1. Partial extraction/full archive confusion, tampered backup URLs, unsafe HTML, failure preserving previous versions.
2. Citation false positives (news quoting title, same-title syndicated articles, bibliography), cycles/ambiguous number, publisher mistaken for issuer.
3. Disabled sources breaking old data validation, bookmarks disappearing, stale/malformed derived indexes.
4. Date/lens/domain/keyword list-count consistency; rolling ranges at midnight; independent page preservation.
5. Slow async fetch/save updates overwriting later state, IndexedDB failure, backup collisions and schema validation.
